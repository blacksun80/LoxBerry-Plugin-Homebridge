This plugin installs Homebridge together with the Config UI X interface on the LoxBerry and runs it as a service. Homebridge runs in its own isolated Node.js runtime; the system Node is left untouched. All configuration (accessories, HomeKit pairing) is done inside the Homebridge interface itself - the plugin has no settings of its own.
